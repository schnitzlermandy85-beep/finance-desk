# 自定义策略接入规范（规划）

Finance Desk 不应直接在页面中执行任意策略脚本。推荐未来通过受控 Python 子进程或独立本地服务运行策略，并只接受标准 JSON 信号。

## 输入

策略获得与当前时间点一致的只读上下文：标的、截至当前 bar 的 OHLCV、已持仓、可用现金、策略参数和交易规则。不会提供应用 API Key、Electron IPC 或文件系统写权限。

## 输出

```json
{
  "signals": [
    {
      "thscode": "600519.SH",
      "action": "target_weight",
      "targetWeight": 0.2,
      "reason": "MA5 位于 MA20 上方"
    }
  ]
}
```

允许动作应限制为 `hold`、`target_weight`、`buy`、`sell`。Finance Desk 统一验证代码、仓位、现金、交易日、费用和风控，再把合法信号转换成模拟订单。

## 运行归档

每次运行应保存策略 ID、文件哈希、参数、数据区间、数据时间戳、信号、订单、净值和错误日志。这样策略版本变化后仍可复现旧结果。

## 安全要求

- 子进程使用固定解释器和受限工作目录。
- 限制执行时间、内存和 stdout 大小。
- 禁止把 API Key 传给策略进程。
- 默认禁网；数据经 JSON stdin 传入。
- 策略不能调用真实交易接口。
